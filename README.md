# Shubham Kumar — Portfolio

Personal portfolio of **Shubham Kumar** — Flutter Developer & Software Engineer (Patna, India).

**Live site:** https://mrshubhamkumar.netlify.app

Dark, minimalist, editorial-style portfolio with smooth scrolling, 3D interactions and subtle animations. Built with zero dependencies — plain HTML/CSS/JS plus CDN-loaded GSAP, ScrollTrigger and Lenis.

## Sections
- Hero with animated name reveal
- About / Profile
- Experience (Flutter Developer · Technical Support · Web Developer/Admin)
- Selected Work (6 projects incl. Nudgr & Auvia)
- Skills, Contact, Education

## Tech
- HTML5 / CSS3 / Vanilla JS
- GSAP + ScrollTrigger (animations), Lenis (smooth scroll)
- Google Fonts: Fraunces, Inter, IBM Plex Mono

## Run locally
Open `index.html` in a browser — no build step.

## Deployment
Auto-deploys from this repo to Netlify at [mrshubhamkumar.netlify.app](https://mrshubhamkumar.netlify.app).
